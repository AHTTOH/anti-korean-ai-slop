# anti-korean-ai-slop

한국어 AI 생성 글에서 반복되는 어색한 번역투, 과잉 평이화, 부자연스러운 어휘 결합, 획일적인 설명문 문체를 교정하기 위한 **Claude Code / Agent Skills 스킬**입니다.

문장의 내용이 아니라 **한국어 표현 방식**을 다룹니다. 특정 단어를 금지하거나 AI 작성 여부를 판정하는 도구가 아닙니다.

## 어떤 문체를 교정하나?

| 관찰되는 표현 | 교정 방향 |
| --- | --- |
| 숫자를 움직여 봅니다 | 입력값을 변경합니다 |
| 결과가 어떻게 흩어지는지 봅니다 | 결과의 분포를 확인합니다 |
| 여기서 숫자와 말을 나눕니다 | 수치 계산과 결과 해석을 분리합니다 |
| 한 가지 예를 보면 쓸모가 보입니다 | 불필요한 안내 문장을 삭제하고 예시로 바로 연결 |
| 짧게 짚습니다 | 불필요한 예고를 생략하고 본문으로 연결 |
| 이렇게 보이면 성공 | 실행 결과 확인 |

위 예시는 **고정 치환표가 아닙니다.** 문맥에 따라 원래 표현이 자연스러울 수도 있습니다. 동일한 단어가 등장한다는 이유만으로 수정하지 않습니다.

문서 전체에서는 범용 동사의 반복, 어색한 관용구, 형식적인 대조 문장, 과도한 메타 서술, 습관적인 문장형 제목과 목록 구성도 검토합니다.

## 설치

[skills CLI](https://github.com/vercel-labs/skills)를 사용해 Claude Code에 전역 설치할 수 있습니다.

~~~bash
npx skills add AHTTOH/anti-korean-ai-slop -g -a claude-code -y
~~~

현재 프로젝트에만 설치하려면 `-g`를 제외합니다.

~~~bash
npx skills add AHTTOH/anti-korean-ai-slop -a claude-code -y
~~~

설치된 스킬 목록은 다음 명령으로 확인할 수 있습니다.

~~~bash
npx skills list -g -a claude-code
~~~

Claude Code 외에 Agent Skills 형식을 지원하는 에이전트에서도 활용할 수 있습니다. 실제 적용과 자동 호출 여부는 사용하는 에이전트의 스킬 지원 방식에 따라 달라집니다.

## 사용 예시

- "이 교육자료의 문체만 교정해 줘. 내용, 수치, 명령어는 그대로 유지해."
- "이 문장에서 번역투와 어색한 한국어 표현을 분석해 줘. 내용의 타당성은 평가하지 마."
- "기술 문서를 작성하되, 한국어의 자연스러운 전문용어를 사용하고 불필요한 비유를 피해서 써 줘."

한국어 작성·교정 요청에 활용하도록 설계했습니다. 스킬을 설치해도 모든 응답에 항상 적용된다는 보장은 없습니다.

## 설계 원칙

1. **문맥 우선:** 금칙어 목록, 고정 치환, 횟수 기준으로 문장을 판단하지 않습니다.
2. **내용 보존:** 문체만 교정할 때 사실, 수치, 코드, 기술 요구사항, 확신의 정도를 임의로 변경하지 않습니다.
3. **자연스러운 전문용어:** 적절한 기술·업무 용어를 부자연스러운 일상 표현으로 바꾸지 않습니다.
4. **과잉 교정 방지:** 자연스러운 문장은 유지하고, 교정 결과에 새로운 정형화된 AI 문체가 생기지 않았는지 확인합니다.
5. **문서별 문체 구분:** 매뉴얼, 보고서, 기사, 블로그, UI 문구를 동일한 말투로 통일하지 않습니다.

세부 실행 지침과 사례는 [SKILL.md](./SKILL.md)에 있습니다.
