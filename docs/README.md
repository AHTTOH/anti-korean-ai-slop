# 한국어 AI 문체 참고 자료

이 디렉터리는 한국어 AI 생성문에서 관찰되는 문체적 특징, 교정 사례, 관련 연구와 아직 검증하지 못한 주장들을 기록한다.

**[SKILL.md](../SKILL.md)는 실행 지침이고, 이 문서들은 토론·분석·사례 축적을 위한 참고 자료다.** 이 디렉터리에 적힌 개별 표현을 금칙어로 적용하거나, 참고 문서 전체가 자동으로 실행된다고 가정하지 않는다.

## 기록 원칙

- **문체만 분석:** 사실관계, 정보량, 논리나 설명의 충분성은 문체 평가에서 제외한다.
- **맥락을 보존:** 한 표현의 자연스러움은 주변 어휘, 문서 장르, 어조, 문단과의 관계에서 판단한다.
- **금칙어 대신 사례:** 예시는 새로운 유형을 발견하기 위한 자료이지, 전면 금지하거나 일대일로 치환할 목록이 아니다.
- **관찰과 검증 분리:** 'AI스럽게 느껴진다'는 평가, 실제 문체 편중을 검증한 연구, 개별 모델의 생성 원인에 대한 주장은 서로 구분한다.
- **의미가 달라지는 교정 금지:** 단어만 비슷한 것으로 바꿔 이동·강화·지속·권고의 의미를 훼손하지 않는다.
- **잘된 문장 보존:** 문제가 없다면 수정할 필요가 없다.

## 추가 사례 제안

새로운 문체 사례는 Issue 또는 Pull Request로 제안할 수 있다. 다음 정보를 권장한다.

1. 원문 문장과 전후 맥락(공개 가능한 범위)
2. 문서의 종류와 독자
3. 어색하게 느껴지는 **언어적** 이유
4. 교정안과 교정이 적절하지 않은 반례
5. 실제 작성자·발생 연도·AI 사용 여부가 확인된 경우 그 근거

이 자료집은 AI 작성 여부를 판정하는 데이터베이스가 아니다.
